## What it reports

The test never compares what the code produced with an expected value: every assertion only checks that a result exists (truthy, defined, not null). The code could return a wrong result and the test would still pass.

## What to do

Compare the result with the value it should have: `toBe`, `toEqual`, `toHaveTextContent`.

`spirolo explain weak-assertion` prints the same claim and status from your installed binary.
