## What it reports

A `.snap` entry is obsolete: no test in its sibling test file writes that key any more, because the test it was taken for was renamed or removed.

## What to do

Delete the entry, or run the runner with `-u`.

`spirolo explain stale-snapshot` prints the same claim and status from your installed binary.
